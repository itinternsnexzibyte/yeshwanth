# Quotation User Guide

1. Sign in with the account created by an administrator.
2. Open **Customers** and confirm customer, contact, GSTIN, address and default terms.
3. Open **New quotation**, then select the customer, contact, template and approved products.
4. Enter quantity, dates, subject, reference, inquiry and freight. Locked prices come from the approved master.
5. Select **Recalculate** and verify subtotal, discount, taxable value, GST, freight and amount in words.
6. Save a draft when incomplete. Select **Save & generate** only when ready to issue.
7. Use **Quotation register** to filter, preview or download Word or **Editable PDF**. The PDF is a native AcroForm: click a value, edit it and save the PDF directly. No conversion website is required. Changes made only inside the downloaded PDF do not change the controlled database record; use **Revise & edit** when the system record must also change.
8. Use **Revise & edit** for an issued quotation so the original remains in history.

Never issue a quotation containing `PENDING` master data.
